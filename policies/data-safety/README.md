# Data Safety

Runtime data safety rules belong here.

This area covers secrets, logs, memory, event journals, user text, audio,
screenshots, local paths, redaction, retention, and data authority boundaries.

Start from inventories. Do not promote legacy notes into formal policy without
current code, tests, or active documentation as evidence.

## Active Drafts

- `memory-stewardship.json`: initial machine-readable policy for broad
  recording, post-save inspection, forgetting, protected memory deletion, and
  evolving classification.
