# Body Display Projection

Body Display Projection is a display-oriented projection service for projector,
background, and display clients.

It does not interpret meaning and it does not decide actions. It reads already
normalized state and produces display-safe frames.

## v0 Contract

- Latest snapshot: `GET /body-display-projection/latest`
- Stream: `WS /body-display-projection/ws`
- Health: `GET /health`
- Payload: `contracts/body_display_projection/body_display_projection.v0.schema.json`

The initial filesystem snapshot used by local verification is generated by
`scripts/build-body-schema-snapshot.ps1` at:

- `.cache/agent-os/body-display-projection/latest.json`

## Update Policy

- Send full frames in v0.
- Reserve `frame_kind: delta` for future use.
- Maximum stream rate: 20 fps.
- Send immediately on meaningful state changes, then throttle.
- Send idle heartbeats when nothing changes.

## Safety

Projection frames must not include:

- raw camera frames
- raw conversation logs
- prompts
- secrets
- local filesystem paths
- action-triggering controls
- driver action catalogs such as `provides_actions`

Projection Background View and other display clients consume this service. They
do not become authorities for system state.
