# Source Inventory Rules

Use inventories before turning legacy or scattered information into formal
rules.

## Priority Order

1. Current code
2. Current tests
3. Current README and active docs
4. Current policies and contracts
5. Legacy docs and archives as reference only

## Classification

- `adopt`: promote to Agent OS rule
- `module-specific`: keep as organ-specific rule
- `exception`: allowed local/debug/probe exception
- `legacy`: reference only
- `investigate`: possible conflict, gap, or unclear authority

Legacy documents can reveal missing topics, but they are not authoritative
without current evidence.
